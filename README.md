# Atividade-alg

Exercícios de algoritmos e estruturas de dados em C, feitos durante a graduação em BTI na UFERSA.

## Estrutura

```
aulas/         aula001.c ... aula038.c   exemplos e exercícios feitos em aula
atividades/    atv039.c  ... atv114.c    atividades de fixação (inclui o sistema de matchmaking com fila)
```

## Como compilar e executar

```bash
gcc aulas/aula001.c -o aula001
./aula001
```

No Windows (MinGW): `gcc aulas/aula001.c -o aula001.exe` e depois `aula001.exe`.
